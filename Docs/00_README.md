# ONE BRAHAM — documentation index

Twenty-one documents. They are written to be read in order by somebody joining
the project, and to be read individually by somebody who needs one answer
quickly.

The rule that governs all of them: **the document is the specification, the script
is the implementation, and `validate_project.py` is the proof.** Where a number
appears in a document it also appears in the source or in the pipeline, and the
validator fails the build if the two disagree.

## The four things this project believes

**1. A building is a better antagonist than a villain.** Everything the game does
that is dramatic comes from a structure: a corridor, a shutter, a stairwell, a
keycard reader. Nobody in ONE BRAHAM is evil and nothing in it is a monster.

**2. Realism is the joke.** The humour is entirely in the situation: a fire drill
notice four days stale, a lost-umbrella poster, a man in a hi-vis vest doing his
job while this is happening. Nobody in this game ever says a funny line.

**3. Precision beats difficulty.** The game is hard because a mistake is a real
mistake, not because a number is large. Every weapon's time-to-kill is documented,
every timer is published, and nothing is randomised that a player has to plan
around.

**4. Nothing ships that cannot be explained.** Every asset in this project is
either generated by a script, or covered by a brief in 15 or a licence in 16. If
neither is true of something, that something is not finished.
