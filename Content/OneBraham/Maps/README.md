# Content/OneBraham/Maps

| Asset | What it is |
| --- | --- |
| `L_Persistent_OneBraham` | The world. ASCENT and NIGHT SHIFT. Persistent level plus one streaming level per floor. |
| `L_FireDrill_Arena` | The FIRE DRILL arena: three points on Lobby, Server Floor and Canteen-Skydeck. |
| `L_MainMenu` | The menu backdrop: a slow camera move down the 15th floor corridor at dawn. |
| `L_Loading` | The loading screen level: black, with the loading widget. |
| `L_Tutorial_SignIn` | The tutorial: ground floor to the lobby, badge in, lift. |
| `L_Benchmark_Skydeck` | The benchmark: a scripted flythrough of every area for the perf pass. |

All six are in the cook list in `Config/DefaultGame.ini`. A map that is not in
that list does not ship - that is the single most common "it works in the editor"
bug in a UE project.

Generated by `Tools/Python/onebraham/build_environment.py`.
