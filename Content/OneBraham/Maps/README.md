# Content/OneBraham/Maps

| Asset | What it is |
| --- | --- |
| `L_MainMenu` | Where a client starts (`GameDefaultMap`) and where a match returns to. Runs `AOneBrahamMenuGameMode`, whose controller puts the code-built main menu on screen. |
| `L_Loading` | The seamless-travel transition map (`TransitionMap`). Runs the engine's base game mode, so no match initialises there. |
| `L_Persistent_OneBraham` | The world. ASCENT and NIGHT SHIFT. Persistent level plus one streaming level per floor (`L_OneBraham_F00` to `F15`). Dedicated servers start here (`ServerDefaultMap`). |
| `L_FireDrill_Arena` | The FIRE DRILL arena: three points on Lobby, Server Floor and Canteen-Skydeck. |

All four are generated by `Tools/Python/onebraham/build_environment.py` and are in
the cook list in `Config/DefaultGame.ini`, each line with a `+`. A map that is not
in that list does not ship, and a `MapsToCook=` line without the `+` silently
replaces the one before it. The floor levels cook as the persistent level's
streaming dependencies.

The benchmark (`ob.Bench.Skydeck`) flies through `L_Persistent_OneBraham` itself;
it has no map of its own. There is no tutorial map: a first match with bots
(PLAY, then *Practice against bots*) is the tutorial.
