# Content/OneBraham

Every asset in the game lives under this folder, with one exception: third-party
marketplace packs are imported into `Content/ThirdParty/<PackName>/` and never
edited in place, so a pack update can be dropped on top without a merge.

## What is generated and what is authored

| Folder | Generated by | Still needs a human |
| --- | --- | --- |
| `Materials/` | `build_materials.py` (node graphs included) | Nothing after the art pass; textures |
| `Environment/` | `build_environment.py` (geometry, areas, props) | Architectural detail meshes |
| `Props/` | `build_props.py` (manifest) + import | Mesh models, textures |
| `Weapons/` | `build_weapons.py` (10 Blueprints) + data assets | Weapon meshes, animations |
| `Characters/` | `build_characters.py` + `apply_cast_payload.py` | MetaHuman-class bodies, cloth, hair |
| `Audio/` | `build_audio.py` (classes, mixes, attenuations, bank) | The actual recordings |
| `VFX/` | `build_vfx.py` (systems, shakes, decals) | The emitter stacks (specs in the sheet) |
| `UI/` | `build_ui.py` (widgets, string table, font slot) | Font choice, final layout polish |
| `Input/` | `build_input.py` (41 actions, 4 contexts) | Nothing |
| `Data/` | `build_weapons.py`, `build_input.py` | Balance tuning |
| `Maps/` | `build_environment.py` | Lighting and polish passes |

Run `Scripts/BuildContent.bat` and all of the generated half appears. The
authored half is listed, per asset, in `Docs/` - and every one of those docs
also names the marketplace pack that can stand in, in
`Docs/16_Marketplace_Fallbacks.md`.

## Do not commit .uasset files produced by a build script

They are reproducible from the scripts and they are large. The convention for
this repo is: scripts and docs are committed, cookable binaries are built and
archived in `Build/`, which `.gitignore` excludes.
