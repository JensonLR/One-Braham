# Content/OneBraham/Input

41 input actions and 4 mapping contexts, generated by `build_input.py` from a
table that mirrors the fields of `UOneBrahamInputConfig` field for field. The
controller binds through that asset and reports any field left null, so an action
that is missing is a key that does nothing rather than a crash.

`IA_<FieldName>` is the naming rule. Do not rename them: the config asset, the
default bindings in `Config/DefaultInput.ini` and the QA checklist all refer to
these names.

Default bindings are written by `generate_input_ini.py`; a player's rebinds are
written to the same section in `GameUserSettings.ini` and take precedence.
