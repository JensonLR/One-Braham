# Content/OneBraham/Environment

The building. Fifteen floors, eight areas, one streaming level per floor.

Generated geometry is box-based blockout at real dimensions (400 cm floor to
floor, 260 cm corridors, 110 cm doors). It is playable, it is correctly scaled,
and it is deliberately plain: the art pass replaces meshes, not layouts.

* Floor list, room programmes and areas: `Tools/Python/onebraham/build_environment.py`
* Art direction, materials, lighting per area: `Docs/10_Environment_Art.md`
* What each area is *for* as a fight: `Docs/09_Map_Implementation.md`
